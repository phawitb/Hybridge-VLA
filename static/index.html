1. System Overview

Hybridge VLA is a Vision-Language-Action system that converts natural language instructions into structured robotic execution plans. It uses Google Gemini VLM models to analyze images and generate step-by-step plans with bounding box coordinates for a single-arm robot with one gripper.

The system provides:

  • Plan generation from natural language instructions via Gemini VLM
  • Automatic prompt generation from a configurable template
  • Plan verification with auto-retry
  • Auto-normalization of pixel bounding boxes to [0,1]
  • Plan visualization with bounding boxes overlaid on images
  • Result storage and historical review

7. Verification Process

After plan generation, Gemini verifies the plan. If it fails, the system retries up to max_retries times.

  1. Infer — Generate plan from image + prompt
  2. Parse — Extract JSON from response
  3. Normalize — Auto-fix pixel bboxes to [0,1]
  4. Verify — Send plan back to Gemini for verification
  5. Retry — If failed, repeat from step 1

Calibration Data

Overview

Camera Calibrate maps pixel coordinates on the top-view camera to robot joint angles, so you can click on the image and the robot arm moves to that physical location.

The system uses a 4-point bilinear interpolation — you teach the robot 4 reference positions, and it interpolates joint angles for any point within that area.

How It Works

1. Calibration (4-point teaching)

You manually move the robot arm (gripper closed, pointing down) to 4 physical locations and record the mapping between pixel position and joint angles.

For each calibration point, the system stores:

  • Pixel coordinate (u, v) — where you clicked on the camera image
  • Joint angles — the 6 joint values when the gripper tip is at that physical location

2. Bilinear Interpolation

joint_value = a + b*u + c*v + d*u*v

With 4 points and 4 unknowns, the system solves exactly for each joint.

3. Height Control

offset = arctan(height_cm / 100 / 0.25)
shoulder_lift -= offset

4. Safety Height & Smooth Arc Path

When moving between positions, the arm follows a sine-bump arc to clear obstacles:

bump(t) = bump_height * sin(pi * t)
bump_height = min(overshoot + 2, 10) degrees
15 waypoints x 40ms = ~0.6s total

Step-by-Step Guide

  1. Go to Config & Test > Debug and press Start to connect the robot
  2. Switch to the Calibrate tab
  3. Press Capture to take a snapshot
  4. Click 4 points on the image, saving robot position for each
  5. Press Compute to finalize calibration
  6. Click anywhere on the image to move the robot

Tips

  • Spread the 4 calibration points as wide as possible for best accuracy
  • Accuracy is highest inside the quadrilateral formed by the 4 points
  • Keep the camera fixed after calibration
  • If the arm folds backward, reduce the Safety height value
Run Plan

Overview

The Run tab executes a VLA plan on the physical robot. It captures an image from the top camera, sends it to Gemini for planning, and then lets you execute each step individually.

How to Use

  1. Ensure robot is connected (Config & Test > Debug > Start)
  2. Ensure camera is calibrated (Calibrate tab)
  3. Select a Gemini model and enter an instruction
  4. Press Plan — captures image from top camera and generates a plan
  5. Review the flowchart and bounding box visualization
  6. Click a step block, then press Run Step to execute it
  7. Steps auto-advance after completion

Step Execution

MethodAction
ik_reach_object_v1Move gripper to bbox center via calibration interpolation with safe arc path
act_gripper_grasp_v1Close gripper (gripper = 0)
act_gripper_release_v1Open gripper (gripper = 100)
act_drawer_open_v1Reach bbox position (placeholder)
act_drawer_close_v1Reach bbox position (placeholder)

Requirements

  • Robot must be connected and cameras streaming
  • Camera calibration must be complete (4-point calibration)
  • Gemini API key must be configured in .env

Troubleshooting

  • "Robot not connected" — Go to Config & Test > Debug and press Start
  • "Not calibrated" — Complete the 4-point calibration in the Calibrate tab
  • Inaccurate movement — Recalibrate with points spread wider across the work area
  • Plan verification failed — The plan may still work; review the steps manually

Datasets — Documents

คู่มืออธิบายการทำงานของแท็บ Datasets อย่างละเอียด ครอบคลุมทุกฟีเจอร์ตั้งแต่การดูข้อมูล, การจัดการ dataset, การทำ augmentation, การ push ขึ้น Hugging Face, ไปจนถึงการเตรียม training command

1. Dataset Explorer

หน้าหลักสำหรับเรียกดูและจัดการ dataset ที่อยู่ในโฟลเดอร์ data/

1.1 เลือก Dataset

  • เลือก dataset จาก dropdown ด้านบน ระบบจะโหลดข้อมูล metadata ทั้งหมด
  • แสดงจำนวน episodes, frames, tasks, FPS และขนาดข้อมูล
  • ถ้า dataset มีหลาย task จะแสดง badge สีแยกตาม task พร้อมจำนวน episodes ต่อ task
  • กด Refresh เพื่ออัพเดตรายชื่อ dataset ใหม่

1.2 เล่นวิดีโอ Episode

  • เลือก episode จากรายการด้านขวา
  • กด Play เพื่อเล่นวิดีโอ top camera และ wrist camera พร้อมกัน
  • ใช้ scrubber ลากเพื่อ seek ไปยังตำแหน่งที่ต้องการ
  • แสดงเวลาปัจจุบันและ phase ของ segment (ถ้ามี)

1.3 Segment Bar (การแบ่งช่วง)

แถบสีด้านล่าง scrubber แสดงการแบ่งช่วงของ episode ออกเป็น phase ต่างๆ เช่น idle, pick up, place

  • คลิก ที่ segment เพื่อเปลี่ยน phase (วนรอบ: idle → pick up → place → idle)
  • ดับเบิลคลิก เพื่อแบ่ง segment ออกเป็น 2 ส่วนตรงจุดที่คลิก
  • ลากขอบ (handle) ซ้าย-ขวา เพื่อปรับขนาด segment
  • ลาก handle จนเหลือ segment เล็กมาก (<2 frames) จะ merge อัตโนมัติ
  • ทุกการเปลี่ยนแปลง save อัตโนมัติ ไปยัง meta/segments.json

1.4 Joint Trajectories Chart

กราฟแสดงค่า action (เส้นทึบ) และ observation.state (เส้นจาง) ของทุก joint ตลอด episode

  • แกน X = frame index, แกน Y = ค่า joint position (radians)
  • 6 joints: shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper
  • เส้นสีแดงแนวตั้ง (cursor) แสดงตำแหน่งปัจจุบันของวิดีโอ
  • พื้นหลังระบายสีตาม segment phase

1.5 Augmentation Grid

ถ้า dataset เป็น augmented dataset จะแสดง grid เปรียบเทียบภาพ

  • คอลัมน์แรก (ขอบเขียว) = ภาพจาก original episode
  • คอลัมน์ถัดไป (ขอบน้ำเงิน) = ภาพที่ผ่านการ augment แต่ละสำเนา
  • แต่ละแถว = 1 source episode กับสำเนา augmented ทั้งหมด
  • ใต้รูปแสดงข้อมูลสรุป params (rotation, brightness, lang)
  • คลิกรูป augmented จะกระโดดไปดู episode นั้นในส่วน player
  • โหลดทีละ 20 แถว กด Load more เพื่อดูเพิ่ม

2. การจัดการ Dataset

2.1 ลบ Episode

  1. กด Select ที่มุมขวาบนของรายการ episodes
  2. เลือก episode ที่ต้องการลบ (ติ๊ก checkbox)
  3. กด Delete ระบบจะลบ episode ที่เลือกและ re-index ข้อมูลใหม่

2.2 ลบ Dataset ทั้งหมด

  • กดปุ่ม Delete Dataset (สีแดง) จะลบโฟลเดอร์ dataset ทั้งหมด
  • มี confirmation dialog ป้องกันการลบผิด

2.3 Combine Datasets

รวม dataset หลายตัวเป็นชุดเดียว

  1. กดปุ่ม Combine (สีน้ำเงิน)
  2. เลือก dataset ที่ต้องการรวม (เลือกได้หลายตัว)
  3. ตั้งชื่อ dataset ใหม่
  4. ระบบจะรวม data parquet, videos, tasks, episodes metadata ให้เป็นชุดเดียว
  5. task_index จะถูก re-map ให้ไม่ซ้ำกัน

2.4 Split & Generate

แยก episode ออกเป็น sub-dataset ตาม phase (เช่น pick up / place) สำหรับ dataset ที่มี task แบบ "pick up X to Y"

  • ปุ่มจะแสดงเฉพาะ dataset ที่มี task ตรงรูปแบบ pick up ... to ...
  • ใช้ segment data จาก meta/segments.json (ถ้ามี) หรือ auto-detect จาก joint data
  • สร้าง sub-dataset ใหม่ เช่น V1_pick-up-the-pink-bow และ V1_place-the-pink-bow

3. Data Augmentation

เพิ่มจำนวน episode ด้วยการสร้างสำเนาที่ปรับเปลี่ยนเล็กน้อย เพื่อให้โมเดลเรียนรู้ได้หลากหลายขึ้น

3.1 วิธีใช้งาน

  1. เลือก dataset แล้วกดปุ่ม Augment (สีส้ม)
  2. ตั้งชื่อ dataset ใหม่
  3. กำหนด Target Episodes = จำนวน episode ที่ต้องการ (ต้อง > จำนวน original)
  4. หรือเลือกจาก Multiplier dropdown (2x, 3x, 5x, 10x)
  5. ปรับ Intensity (1-5) เพื่อควบคุมความแรงของการเปลี่ยนแปลง
  6. เลือก techniques ที่ต้องการ แล้วกด Start Augmentation

3.2 เทคนิค Augmentation

Camera Shift

ปรับมุมกล้องเสมือน ทำให้โมเดลทนต่อการเปลี่ยนตำแหน่งกล้อง

  • Perspective warp — บิดภาพเล็กน้อยเสมือนมุมกล้องเปลี่ยน
  • Affine transform — ขยาย/หด/เลื่อน/เอียงภาพ
  • Rotation — หมุนภาพเล็กน้อย

Light & Quality

ปรับแสงและคุณภาพภาพ เสมือนถ่ายในสภาพแสงต่างๆ

  • Brightness — ปรับความสว่าง
  • Saturation — ปรับความอิ่มตัวสี
  • Color jitter — เปลี่ยนโทนสีเล็กน้อย
  • Shadow — เพิ่มเงาสุ่ม
  • Noise — เพิ่ม Gaussian noise
  • Blur — เบลอภาพเล็กน้อย

Language Augmentation

ปรับเปลี่ยนข้อความ task description เพื่อให้โมเดลเข้าใจคำสั่งที่หลากหลาย

  • Paraphrase — เปลี่ยนคำพูดให้มีความหมายเดียวกัน (เช่น "pick up" → "grab", "lift")
  • Synonym — สลับคำใกล้เคียง
  • Typo — เพิ่ม typo เล็กน้อยเสมือนผู้ใช้พิมพ์ผิด

Robot Noise

เพิ่ม noise ในข้อมูล joint เสมือนหุ่นยนต์มีความคลาดเคลื่อนเล็กน้อย

  • Random start — ตัด frame เริ่มต้นออก (trim)
  • Initial noise — เพิ่ม offset ให้ joint ตอนเริ่มต้น
  • Trajectory jitter — เพิ่ม noise ตลอดเส้นทาง

3.4 การกระจาย Episode

ระบบจะกระจาย target episodes ให้เท่าๆ กันในทุก source episode

target = 870, source = 174 episodes
base = 870 / 174 = 5 copies ต่อ episode
remainder = 870 % 174 = 0
ทุก episode จะได้ 5 สำเนา (1 original + 4 augmented)

ถ้าหารไม่ลงตัว episode แรกๆ จะได้ +1 copy เพื่อให้ครบตามเป้า

Run inference with augmented cameras — no code changes needed. Save params first, then copy the command below.

python fakecam_inject.py --params-file fakecam_params.json -- lerobot-rollout ...

Or load params from server in real-time:

python fakecam_inject.py --from-server http://localhost:8000 -- lerobot-rollout ...

How to use Fake Camera in Inference
  1. Preview — Set camera indices, click Start to see augmented live preview. Adjust sliders until satisfied.
  2. Save Params — Click Save Params to save augmentation settings to fakecam_params.json
  3. Run Inference — Use fakecam_inject.py to wrap your inference command. It monkey-patches cv2.VideoCapture.read() so all camera frames are augmented automatically — no code changes needed.
  4. Works everywhere — No virtual camera device or OBS required. Works on macOS, Linux, any number of cameras.
