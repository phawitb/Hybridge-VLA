1. System Overview

Hybridge VLA is a Vision-Language-Action system that converts natural language instructions into structured robotic execution plans. It uses Google Gemini VLM models to analyze images and generate step-by-step plans with bounding box coordinates for a single-arm robot with one gripper.

The system provides:

  • Plan generation from natural language instructions via Gemini VLM
  • Automatic prompt generation from a configurable template
  • Plan verification with auto-retry
  • Auto-normalization of pixel bounding boxes to [0,1]
  • Plan visualization with bounding boxes overlaid on images
  • Result storage and historical review

7. Verification Process

After plan generation, Gemini verifies the plan. If it fails, the system retries up to max_retries times.

  1. Infer — Generate plan from image + prompt
  2. Parse — Extract JSON from response
  3. Normalize — Auto-fix pixel bboxes to [0,1]
  4. Verify — Send plan back to Gemini for verification
  5. Retry — If failed, repeat from step 1

Overview

Camera Calibrate maps pixel coordinates on the top-view camera to robot joint angles, so you can click on the image and the robot arm moves to that physical location.

The system uses a 4-point bilinear interpolation — you teach the robot 4 reference positions, and it interpolates joint angles for any point within that area.

How It Works

1. Calibration (4-point teaching)

You manually move the robot arm (gripper closed, pointing down) to 4 physical locations and record the mapping between pixel position and joint angles.

For each calibration point, the system stores:

  • Pixel coordinate (u, v) — where you clicked on the camera image
  • Joint angles — the 6 joint values when the gripper tip is at that physical location

2. Bilinear Interpolation

joint_value = a + b*u + c*v + d*u*v

With 4 points and 4 unknowns, the system solves exactly for each joint.

3. Height Control

offset = arctan(height_cm / 100 / 0.25)
shoulder_lift -= offset

4. Safety Height & Smooth Arc Path

When moving between positions, the arm follows a sine-bump arc to clear obstacles:

bump(t) = bump_height * sin(pi * t)
bump_height = min(overshoot + 2, 10) degrees
15 waypoints x 40ms = ~0.6s total

Step-by-Step Guide

  1. Go to Config & Test > Debug and press Start to connect the robot
  2. Switch to the Calibrate tab
  3. Press Capture to take a snapshot
  4. Click 4 points on the image, saving robot position for each
  5. Press Compute to finalize calibration
  6. Click anywhere on the image to move the robot

Tips

  • Spread the 4 calibration points as wide as possible for best accuracy
  • Accuracy is highest inside the quadrilateral formed by the 4 points
  • Keep the camera fixed after calibration
  • If the arm folds backward, reduce the Safety height value
Run Plan

Overview

The Run tab executes a VLA plan on the physical robot. It captures an image from the top camera, sends it to Gemini for planning, and then lets you execute each step individually.

How to Use

  1. Ensure robot is connected (Config & Test > Debug > Start)
  2. Ensure camera is calibrated (Calibrate tab)
  3. Select a Gemini model and enter an instruction
  4. Press Plan — captures image from top camera and generates a plan
  5. Review the flowchart and bounding box visualization
  6. Click a step block, then press Run Step to execute it
  7. Steps auto-advance after completion

Step Execution

MethodAction
ik_reach_object_v1Move gripper to bbox center via calibration interpolation with safe arc path
act_gripper_grasp_v1Close gripper (gripper = 0)
act_gripper_release_v1Open gripper (gripper = 100)
act_drawer_open_v1Reach bbox position (placeholder)
act_drawer_close_v1Reach bbox position (placeholder)

Requirements

  • Robot must be connected and cameras streaming
  • Camera calibration must be complete (4-point calibration)
  • Gemini API key must be configured in .env

Troubleshooting

  • "Robot not connected" — Go to Config & Test > Debug and press Start
  • "Not calibrated" — Complete the 4-point calibration in the Calibrate tab
  • Inaccurate movement — Recalibrate with points spread wider across the work area
  • Plan verification failed — The plan may still work; review the steps manually
